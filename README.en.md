# Scholarly Database Review: Encrypted Preview

[Preview entry](https://lavineyangleo.github.io/scholarly-database-api-preview/). Ask the sender for the complete link containing the decryption credential.

The report compares actual fields from a WoS web export, OpenAlex, Semantic Scholar and Scopus, including the same DOI and S2 rate-limit retries.

## Usage and access

The complete link decrypts the AES-256-GCM report inside the browser. Read HTML or preview/download Markdown. Anyone with the complete link can access and forward it. This repository contains only the gateway and encrypted payload, without keys, plaintext reports or raw responses.

GitHub Pages publishes the main branch root. Never commit access credentials. Reports contain historical tests, not live provider calls.
