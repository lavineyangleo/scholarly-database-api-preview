# 科技文献数据库评测：加密预览

[打开预览入口](https://lavineyangleo.github.io/scholarly-database-api-preview/)。需要分享者提供包含解密凭证的完整链接。

比较 WoS 网页导出、OpenAlex、Semantic Scholar 和 Scopus 的实际字段。报告包含同一 DOI 的真实对照及 S2 限流重测。

## 使用与访问

完整链接在浏览器内解密 AES-256-GCM 报告；可阅读 HTML、预览或下载 Markdown。持有完整链接的人均可访问并转发。仓库只包含解密界面和密文，密钥、明文报告及原始响应未发布。

GitHub Pages 发布 main 根目录。不要把访问凭证提交到仓库。报告是历史评测，不实时请求供应商 API。
